# 更新日志

## v2.0.0（开发中）

<Badge type="warning" text="待实机验收" /> <Badge type="tip" text="2026-09-28" />

TAdmin 2 是一次彻底重写。旧版本只做“入群验证码”，依赖 HTTPS 域名与 Mini App，设置要靠命令完成；新版本以“个人自托管、零配置、按钮操作”为目标重新设计。

### 新功能

- **五种投递方式**：浮层（Bot API 10.2 临时消息，仅本人可见）、群内、私聊、入群申请、Guard（Bot API 10.1）。
- **三种题型**：图形点选（数字与形状双重歧义，抗单一识别）、图片算术、一键确认；答案从不离开服务器。
- **私聊按钮控制台**：群组、验证、欢迎语、频道、清理、防护、统计、待处理、预览刷新、系统，全部原地编辑。
- **频道联动**：自动取消 / 只保留最新频道置顶、一键清理历史频道置顶且保留管理员置顶、拦截频道马甲。
- **链接预览刷新**：sitemap / RSS / Atom / JSON Feed 自动发现与变更检测，慢速队列通过 @WebpageBot 刷新；用户号扫码登录与内联键盘验证码。
- **防护**：突击防护、CAS 联防、拦截非管理员拉入的机器人、可选 AI 入群资料风险提示（只升级处理）。
- **欢迎语与清理**：保留 Telegram 格式的欢迎语、链接按钮、仅本人可见、定时删除；服务消息清理。
- **管理员命令**：`/pass` `/kick` `/ban` `/mute` `/unmute` `/unban` `/unpin` `/settings` `/status`。
- **统计与备份**：14 天迷你柱状图、通过率与中位用时；数据库一键备份到私聊，或 `tadmin backup` 在线快照。
- **零配置部署**：只需 `TADMIN_BOT_TOKEN` 与 `TADMIN_OWNER_ID`；`scratch` Docker 镜像、systemd 模板、内置时区数据库、`healthcheck` 子命令。
- **文档站**：本站。配置、命令、数据结构、测试统计、验证码样例与项目进度由 `cmd/docgen` 从代码生成并受测试保护。

### 可靠性与安全（两轮独立审查后修复）

- 非所有者无法通过深链或面板按钮激活“待授权”的群；待审核名单不再泄露给无关用户。
- 带 `until_date` 的调用不在客户端内部重试 429，最短封禁提高到 2 分钟，避免封禁退化为永久。
- 入群服务消息与 `chat_member` 更新的先后顺序不再影响豁免判断；有未完成申请的人改走直接入群也会被验证。
- 离群重进时不再把 TAdmin 自己的禁言误当成管理员限制；离群时解除残留禁言。
- 入群只在更新路径上同步完成禁言，检查与投递交给调度器；私聊控制台的慢操作使用独立队列；消息删除移出调度主循环。
- Guard 查询过期后改用普通批准 / 拒绝接口；题目无法投递时直接转人工，到期放行而不惩罚用户。
- 预览刷新的 24 小时去重、最小间隔与每日上限不再能被绕过。
- 欢迎语的嵌套格式生成正确的 HTML；2FA 密码与验证码输入的会话处理更严格；登录调用增加超时；关闭时等待后台任务完成。
