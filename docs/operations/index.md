# 日常运维

运行数据按保留策略自动清理；维护者仍需定期检查备份、磁盘、权限告警和依赖更新。首次试用先完成 [本地准备](/operations/preflight) 与 [实群验收](/operations/acceptance)。

## 看状态

| 在哪看 | 看什么 |
|---|---|
| 私聊控制台首页 | 今日入群、通过、拦截、进行中的验证，以及需要处理的提醒 |
| 群页面 | 权限问题、近 7 日数据、中位答题用时 |
| 📋 待处理 | 进行中的验证与卡住的原因，可一键放行 / 移除 / 封禁 |
| ⚙️ 系统 | 版本、运行时长、数据库大小、Mini App / 用户号 / AI 状态 |
| `GET /healthz` | 进程与数据库是否正常（不代表 Telegram 可达） |

## 日志

结构化 JSON 输出到 stdout（`log_format = "text"` 可切换为文本，`log_level` 调整级别）。**不会**记录 Bot Token、Mini App initData、验证码答案、手机号、登录验证码或密码。

```sh
docker compose logs -f          # Docker
journalctl -u tadmin -f         # systemd
```

## 告警

以下情况会私聊所有者，同类告警 10 分钟内只发一次；正常通过的验证不会打扰你：

- 机器人在某群缺少权限、Telegram 拒绝了动作；
- 触发突击防护；
- 审核卡无法投递；
- 机器人被移出群、权限变化。

## 数据保留

| 数据 | 保留时长 |
|---|---|
| 进行中的验证 | 直到结束 |
| 已结束的验证 | 30 天（用于统计与递增冷却） |
| 统计与审计事件 | 90 天 |
| 频道置顶记录、预览链接 | 180 天 |
| 群设置、订阅源、用户号会话 | 直到删除 |

清理每小时自动运行一次，不会删除进行中的流程。

## Token 轮换

1. @BotFather → `/revoke` 生成新 Token。
2. 更新 `TADMIN_BOT_TOKEN` 并重启。旧 Token 立即失效；已打开的 Mini App 页面需要重新打开。
