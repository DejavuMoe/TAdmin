# 故障排查

## 启动

| 现象 | 原因与处理 |
|---|---|
| `invalid configuration: …` | 按提示补齐变量；必填的只有 `TADMIN_BOT_TOKEN` 与 `TADMIN_OWNER_ID` |
| `Telegram rejected the bot token (401/404)` | Token 错误或已被 `/revoke`，到 @BotFather 重新获取 |
| `database is in use by another TAdmin instance` | 同一数据目录已有实例运行（单实例文件锁），先停掉旧实例 |
| 日志反复出现 `409 Conflict` | 同一 Token 有另一个进程在轮询。TAdmin 启动时会自动删除 webhook，但无法停止别处的进程 |
| `cannot message the owner yet` | 在 Telegram 里给机器人发一次 `/start` |

## 入群验证

| 现象 | 排查 |
|---|---|
| 新人没有被禁言 | 控制台 → 群 → 🔍 权限检查：必须是超级群、机器人需要“封禁用户”；群状态不能是“已暂停”或“待授权” |
| 新人看不到题目 | 浮层模式依赖 Bot API 10.3 临时消息，老客户端可能不显示——新人点提示里的“开始验证”可尝试重新投递；实际支持需按客户端版本验收；也可以改用“群内”或“私聊”模式 |
| 管理员点审核按钮没反应 | 需要该群的“封禁用户”权限；匿名管理员无法操作 |
| 频道讨论群的评论者没被验证 | 讨论群需要开启“加入后才能发言” |
| 有人被卡在验证里 | 📋 待处理 中查看原因（上次错误会显示在条目下方），手动放行或移除 |

## 其他

| 现象 | 排查 |
|---|---|
| 群里还能看到“X 加入了群组” | 🧹 消息清理 中打开“入群提示”；机器人需要“删除消息” |
| 频道置顶没被取消 | 机器人需要“置顶消息”；频道联动中确认策略不是“保持原样” |
| 预览刷新一直不动 | 🔄 预览刷新 页面查看用户号状态、限流剩余时间和每日上限 |
| 统计日期不对 | 设置 `TADMIN_TIMEZONE` |
| 欢迎语发送失败 | 用 👁 预览效果 检查；通常是模板中的 HTML 不完整 |
