# TAdmin 是什么

<p class="lead">TAdmin 是一个为<b>个人自托管</b>设计的 Telegram 群管机器人：它把新成员挡在门口，直到确认对方是真人；而对已经在群里的朋友，它什么都不看、什么都不管。</p>

## 三条设计原则

**只守门，不审查。** TAdmin 处理的是“入群”这一刻：验证、频道联动、服务消息清理。它不分析、不评分、不处罚已入群成员的发言内容——你的群聊属于你的群友。

**不永久误伤。** 验证失败的结果是“移出 + 递增冷却”，封禁到期自动解除；永久封禁只能由管理员手动执行。管理员事先设置的个人限制，在对方通过验证后原样恢复。

**零运维负担。** 一个静态二进制、一个 SQLite 文件，只需要 Bot Token 和你的 Telegram ID。没有域名、没有数据库服务、没有 Redis；Mini App、用户号、AI 都是可选增强，缺失时对应功能自动隐藏。

## 它能做什么

| 能力 | 说明 |
|---|---|
| 🔐 入群验证 | 浮层 / 群内 / 私聊 / 入群申请 / Guard 五种投递方式；图形点选、图片算术、一键确认三种题型 |
| 🧑‍⚖️ 人工兜底 | 新人可以“求助”，管理员在群里一键放行、移除或封禁 |
| 🌊 突击防护 | 入群激增时自动收敛提示、缩短时限，并私聊通知你 |
| 📢 频道联动 | 自动取消频道置顶、一键清理历史频道置顶、拦截频道马甲 |
| 🔄 预览刷新 | 订阅 sitemap / RSS，页面更新后慢速刷新 Telegram 链接预览 |
| 👋 欢迎与清理 | 仅本人可见的欢迎语、自动删除服务消息 |
| 👮 管理命令 | `/pass` `/kick` `/ban 7d` `/mute 2h` `/unpin` 等回复命令 |
| 📊 统计与备份 | 14 天趋势、通过率、中位用时；数据库一键备份到私聊 |

## 刻意不做什么

- **不做内容审核**：没有关键词过滤、广告识别、刷屏评分或自动处罚。
- **不做 Web 后台**：Telegram 私聊就是控制台。
- **不做多租户与集群**：一个实例、一个数据库、一个 Bot Token。
- **不承诺挡住一切**：验证码显著抬高批量自动入群的成本，但挡不住真人广告号或专门训练的识别脚本。

::: tip 适合谁
几个到几十个群、希望“新人进来先证明自己是人，其余时间机器人最好隐形”的群主与管理员。
:::
