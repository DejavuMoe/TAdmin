# 权限与角色

## 机器人需要的群管理员权限

| 权限 | 用途 | 缺失时 |
|---|---|---|
| 封禁用户 | 禁言新成员、移出未通过者 | ❌ 验证无法工作 |
| 删除消息 | 清理提示、服务消息、未验证者的消息 | 提示与服务消息会残留 |
| 置顶消息 | 取消频道自动置顶 | 频道联动不可用 |
| 邀请用户 | 批准 / 拒绝入群申请 | 入群申请模式不可用 |

机器人进群时会自动检查一遍并私聊你结果；之后权限变化（被降权、被移出）也会提醒。随时可以在控制台 **🔍 权限检查** 里重查。群必须是**超级群**。

## 三种角色

| 角色 | 如何认定 | 能做什么 |
|---|---|---|
| 所有者 | 配置中的 `owner_id` | 全部：所有群、预览刷新、用户号、系统与备份、移除群组、授权新群 |
| 群管理员 | 实时读取 `getChatAdministrators`（缓存 10 分钟，成员变更即时失效），需有“封禁用户”权限 | 自己所在群的设置面板、审核按钮、群内回复命令；置顶相关操作还需“置顶消息”权限 |
| 普通成员 | — | 回答属于自己的验证题、请求人工帮助 |

::: info 机器人不会放大权限
群管理员只能通过 TAdmin 做他本来就有权做的事：没有“置顶消息”权限的管理员无法用 TAdmin 取消置顶；管理员也看不到其他群、系统设置或预览刷新。
:::

## 授权新群

- **所有者**把机器人拉进群：直接启用。
- **其他人**把机器人拉进群：群进入“待授权”状态，机器人在该群不做任何事，并私聊所有者一张卡片 **[✅ 授权管理] [🚪 退出该群]**。待授权的群对非所有者完全不可见、不可操作。

## 匿名管理员

以群身份发言的匿名管理员无法确认是谁，所以不能使用群内命令或点击审核按钮——请切换回本人身份。
