# 防护与安全

除了验证码本身，TAdmin 还有几道只针对“门口”的防线。它们都在控制台 **🛡 防护与安全** 中开关。

## 突击防护

当 1 分钟内的入群人数达到阈值（默认 10 人，可设 5 / 10 / 20 / 30 / 50 或关闭），群进入防护期（默认 15 分钟）：

- **不再为每个人发公开欢迎提示**，只推送仅本人可见的题目，并在群里发一条共享的 **🔐 开始验证** 按钮——任何新人点它都会打开自己的题目。
- 新验证的时限缩短到 **90 秒**以内；群内公开模式临时改为浮层模式。
- 私聊通知所有者，附 **✅ 立即解除防护** 按钮。

## 拦截机器人

非管理员把机器人账号拉进群时，TAdmin 立即将其移除并在群里简短提示。管理员拉入的机器人不受影响。

## 未验证者的消息

新成员在禁言生效之前发出的消息（网络延迟造成的窗口），只要他的验证尚未结束，就会被删除。这是门禁的一部分，与消息内容无关。

## CAS 联防

开启后，每位新成员入群时查询 [CAS](https://cas.chat) 公共垃圾账号库；命中者直接封禁 30 天。

::: warning 隐私提示
开启 CAS 会把新成员的 Telegram 用户 ID 发送给 cas.chat。默认关闭。
:::

## AI 入群资料风险提示

配置 `TADMIN_TYPESAFE_API_KEY` 后可用。默认使用 TypeSafe Jev，也可切换到[自部署 Laya Multilingual](/guide/laya)。TAdmin 把新成员的**公开资料**（昵称、用户名、简介）与群名称发给选定服务，在同一请求里询问 5 个窄问题：

| 判断 | 是否计入风险 |
|---|---|
| 是否在推广与本群主题无关的买卖、招募 | ✅ |
| 是否在推广金融骗局、快速致富或赌博 | ✅ |
| 是否在推广色情内容或服务 | ✅ |
| 是否冒充管理员、客服或官方账号 | ✅ |
| 昵称或简介是否像广告排版 | 仅参考 |

风险值取四项“严重”判断的最大值。三种模式：

- **关闭**（默认）。
- **仅提示**：风险值显示在人工审核卡上，不影响流程。
- **高风险转人工**：高风险者即使答对，也要管理员确认后才放行。

Laya 首阶段强制仅提示：控制台只有“关闭 / 仅提示”，已有“高风险转人工”设置按“仅提示”执行，不改变数据库原偏好。Jev 保留上述三种模式。

::: info AI 只会让流程更严格
AI 结果永远不会自动放行、也不会自动封禁。不发送用户 ID，不发送任何群聊消息；空简介、随机昵称、非拉丁文字不会被当作风险。阈值只是起点，应在你的真实数据上观察后再依赖。
:::

## 频道马甲

以其他频道身份在群里发言会被删除，并封禁该频道身份（关联频道与匿名管理员除外）。详见 [频道联动](./channel)。
