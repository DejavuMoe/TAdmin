# 频道联动

频道开启讨论群后，每条频道新帖都会自动转发到讨论群，并且**默认被置顶**——群里的置顶很快就被频道帖子淹没了。TAdmin 可以管住它。

## 自动置顶策略

| 模式 | 效果 |
|---|---|
| 保持原样 | 不干预 |
| 自动取消 | 频道新帖一到就取消置顶 |
| 只保留最新一条 | 新帖保持置顶，上一条频道置顶自动取消 |

TAdmin 会稍等约 2 秒再取消置顶（Telegram 在转发之后才应用自动置顶，立即取消可能扑空），失败时自动重试。

## 一键清理历史频道置顶

控制台 **📢 频道联动 → 🧹 一键清理频道置顶**，或在群里发送 `/unpin`：

1. 先取消所有记录在案的频道转发置顶；
2. 再反复查看群当前最上层的置顶——只要来自关联频道就取消，**遇到管理员置顶即停**。

所以管理员自己置顶的群规、公告都会原样保留。

::: tip 更早的频道置顶
如果某条管理员置顶压在一批频道置顶上面，“最上层”检查会在那里停下。需要继续清理时，先临时取消那条管理员置顶再执行一次。
:::

需要彻底清空时，还有 **⚠️ 取消全部置顶（含管理员）**，执行前会二次确认。置顶相关操作要求操作者本人拥有“置顶消息”权限。

## 拦截频道马甲

开启后，以**其他频道**身份在群里发言的消息会被删除，并通过 `banChatSenderChat` 封禁该频道身份。以下身份不受影响：

- 关联频道本身（频道帖的自动转发、以频道身份的评论）；
- 以群身份发言的匿名管理员。

这是身份规则，不看消息内容。
