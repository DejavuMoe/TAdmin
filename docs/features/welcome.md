# 欢迎语与消息清理

## 欢迎语

新成员**通过验证后**才会收到欢迎语。在控制台 **👋 欢迎语** 中设置：

| 选项 | 说明 |
|---|---|
| 可见范围 | 👁 仅新人可见（默认，临时消息）或 📣 所有人可见 |
| 自动删除 | 不删除 / 1 分钟 / 5 分钟 / 30 分钟 / 1 小时 |
| 文案 | 直接用 Telegram 的粗体、斜体、链接等格式编写，TAdmin 会原样保留 |
| 按钮 | 每行一排链接按钮 |

**占位符**

| 占位符 | 替换为 |
|---|---|
| `{mention}` | 可点击的新成员名字 |
| `{name}` | 新成员名字（纯文本） |
| `{username}` | `@用户名`（没有则为空） |
| `{group}` | 群名称 |

**按钮格式**：每行一排，`文字 - 链接`，同一排多个按钮用 `|` 分隔。

```text
📜 群规 - https://t.me/example/1 | 💬 频道 - https://t.me/example
🐙 GitHub - https://github.com/example
```

设置完成后点 **👁 预览效果**，机器人会把渲染后的欢迎语私聊给你。

## 服务消息清理

在 **🧹 消息清理** 中选择要自动删除的服务消息：

| 类型 | 默认 |
|---|---|
| “X 加入了群组” | ✅ 删除 |
| “X 离开了群组” | ✅ 删除 |
| “X 置顶了消息” | 保留 |
| 改名、换头像、语音通话、助力等 | 保留 |
| 管理员命令与机器人的回复（约 30 秒后） | ✅ 删除 |

验证用的提示、题目和审核卡无论如何都会在流程结束后自动清理；审核卡会先显示处理结果和处理人，1 分钟后删除。
