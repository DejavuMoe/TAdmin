# 私聊控制台

TAdmin 没有 Web 后台——Telegram 私聊就是控制台。发送 `/start` 打开首页，所有页面都在同一条消息里原地切换，不会刷屏。

## 交互细节

- **原地编辑**：点按钮切换页面、修改设置时，机器人编辑同一条消息，而不是发新消息。
- **即时生效**：每次点击直接写入数据库并重新渲染，返回按钮永远在最后一行。
- **文字输入**：编辑欢迎语、添加订阅源、输入手机号时，机器人会提示你发送一条消息；15 分钟内有效，发送 `/cancel` 取消。敏感输入（手机号、密码）读取后立即删除。
- **慢操作不阻塞**：发现订阅源、刷新预览、备份这类耗时操作在独立队列中执行，永远不会拖慢群里的入群验证。
- **试玩**：每个群都能 **🎮 试玩验证题**，三种题型随时切换。

## 共同管理

群管理员（需有“封禁用户”权限）在群里发送 `/settings`，就会在私聊收到**该群**的设置面板；也可以私聊 `/start` 查看自己能管理的群。他们看不到其他群、系统设置与预览刷新，也不能移除群组。
